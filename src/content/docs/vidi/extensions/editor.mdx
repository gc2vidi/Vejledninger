## Hvad er Editor-udvidelsen?

Editor-udvidelsen gør det muligt at redigere geografiske features direkte i Vidi. Du kan oprette nye features, flytte eksisterende, ændre attributter og slette features – alt sammen uden at bruge desktop-GIS.

:::caution[Vigtigt: Kræver konfiguration]
Editor-udvidelsen kræver:
- Udvidelsen skal findes i Vidi-installationen og være aktiveret i Vidi-konfigurationen
- Laget skal være gjort editerbart i GC2
- Din bruger skal have de korrekte privilegier i GC2

Kontakt din systemadministrator for opsætning.
:::

:::note[GC2-konfiguration]
[Læs mere om opsætning af editerbare lag i GC2 →](/gc2/skemaindstillinger/database/editerbare-lag)

[Læs mere om funktioner i Vidi-konfigurationen →](/gc2/konfigurationer/soegning-funktioner-og-udseende)

[Læs mere om privilegier i GC2 →](/gc2/skemaindstillinger/database/privilegier-og-authentication)
:::

## Hvad kan redigeres?

Med Editor-udvidelsen kan du:

- ✏️ **Oprette** nye features (punkter, linjer, polygoner)
- 🔄 **Flytte** eksisterende features
- ✂️ **Ændre geometri** (tilføj/fjern knudepunkter)
- 📝 **Redigere attributter** (tekstfelter, numre, datoer)
- 🗑️ **Slette** features

## Adgang til editor

Editor-funktionen er integreret i **Infoværktøjet**:

1. Klik på **info-ikonet** i Vidi-menuen
2. **Klik på en feature** fra et editerbart lag
3. Info-popup vises med **"Rediger"**-knap
4. Klik på **"Rediger"**-knappen for at starte redigering

[Læs mere om infoværktøjet →](/vidi/vidi-menuen/infovaerktoj)


## Tegn ny feature

1. Klik på <MenuPath items="+" /> knappen ud for det lag, hvor der skal oprettes nye features
2. **Tegn på kortet**:
   - **Punkt:** Klik for at placere
   - **Linje:** Klik for hvert knudepunkt, dobbeltklik for at afslutte
   - **Polygon:** Klik for hvert hjørne, klik på startpunkt for at lukke
3. **Udfyld attributter** i formular
4. Klik **"Gem"** for at oprette featuren

## Slet features

1. **Klik på featuren** med infoværktøj
2. Klik på skraldespandsknappen <MenuPath items="🗑" />
3. **Bekræft sletning**
4. Featuren slettes fra databasen

:::warning[Vigtigt]
Når en feature slettes, kan den typisk ikke genskabes (medmindre der er opsat versionskontrol i GC2 eller i databasen).
:::

## Redigér attributter

1. **Klik på featuren** med infoværktøj
2. Klik **"Rediger"**-knappen
3. En **formular** vises med alle attributter
4. **Ændr værdier** i felterne
5. Klik **"Gem"** for at gemme ændringer

## Redigér geometri

### Flyt punkter

1. **Klik på punktet** med infoværktøj
2. Klik **"Rediger"**
3. **Træk punktet** til ny position
4. Klik **"Gem"** for at gemme ændringen

### Ændre knudepunkter

For linjer og polygoner:

1. **Klik på featuren** med infoværktøj
2. Klik **"Rediger"**
3. **Knudepunkter** vises som hvide kasser
4. **Træk knudepunkter** for at ændre form
5. Tilføj et nyt knudepunkt ved at trykke på den afdæmpede hvide kasse, der er mellem knudepunkterne. Fjern knudepunkter ved at venstreklikke på dem
6. Klik **"Gem"** for at gemme
