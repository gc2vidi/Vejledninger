## Hvad er GC2?

GeoCloud2, forkortet GC2, er administrationsplatformen bag Vidi. Her organiserer administratoren data, lag, metadata, adgang, tjenester og de konfigurationer, som bestemmer Vidi-løsningens indhold og opstart.

I samspillet:

- PostgreSQL gemmer data og struktur
- GC2 administrerer lag, metadata, rettigheder og tjenester
- Vidi viser kort og værktøjer til slutbrugeren
- QGIS og andre klienter kan bruge de samme data gennem database- eller serviceforbindelser

## Hvem er dokumentationen til?

GC2-delen er skrevet til administratorer og GIS-fagpersoner, som:

- opretter brugere og adgangsprofiler
- opretter, importerer og organiserer lag
- konfigurerer felter, Meta, styling og labels
- gør lag redigerbare
- publicerer Vidi-konfigurationer
- arbejder med tjenester, QGIS, Workflow eller Scheduler

:::tip[Afgrænsning]
Vi forventer, at GC2 og Vidi allerede er installeret. Begrænset server- og buildkontekst findes under [Admin-drift og fejlsøgning](/gc2/admin-drift-og-fejlsoegning), når den er nødvendig for administrationen.
:::

## Anbefalet læringssti

1. [Log ind og forstå dashboardet](/gc2/log-ind-og-dashboard).
2. [Opret brugere og adgangsprofiler](/gc2/brugere-og-adgang).
3. Åbn [Skemaindstillinger](/gc2/skemaindstillinger).
4. Begynd i [Database](/gc2/skemaindstillinger/database) med lag, felter, adgang og Meta.
5. Fortsæt i [Kort](/gc2/skemaindstillinger/kort) med styling og labels.
6. Brug kun [Workflow](/gc2/skemaindstillinger/workflow) og [Scheduler](/gc2/skemaindstillinger/scheduler), når arbejdsprocessen kræver det.
7. Saml de færdige lag under [Konfigurationer](/gc2/konfigurationer).
