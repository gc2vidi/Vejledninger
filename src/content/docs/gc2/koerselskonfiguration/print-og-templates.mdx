## Hvad styrer denne del?

Print og templates handler om hvordan Vidi ser ud, og hvilke layoutmuligheder brugeren får når der printes eller arbejdes i specialvisninger som embed.

## Printskabeloner

Printmuligheder styres normalt gennem konfigurationen. Her angiver du hvilke templates der må bruges i printdialogen.

Det vigtigste felt er ofte:

```json
{
  "enabledPrints": ["print", "print_sagsbehandler"]
}
```

Hvis der kun er en enkelt printskabelon, får brugeren et enklere valg i Vidi. Hvis der er flere, kan brugeren skifte mellem dem i printdialogen.

## `template`

Med `template` vælger du hvilket layout Vidi skal bruge som udgangspunkt.

```json
{
  "template": "default.tmpl"
}
```

Templates bruges ikke kun til print. De kan også påvirke den samlede brugerflade, fx hvis en løsning skal være mere kompakt eller passe til en indlejret visning.

Vidi bruger templates flere steder:

- til det overordnede layout
- til embed-visninger
- til indhold i feature-info og popup-visninger
- til visning af enkelte felter i særlige værktøjer

Template-systemet bygger på Handlebars. Det betyder at du kan bruge placeholders som `{{feltnavn}}` og i nogle tilfælde også hjælpefunktioner til formatering.

Et enkelt eksempel på en felt-template kan være:

```handlebars
Lokalplan nr: {{plannr}} <br>
Vedtaget den: {{vedtagetdato}}
```

Nyttige hjælpefunktioner fra den ældre Vidi-dokumentation er blandt andet:

- `formatDate` til datoformatering
- `replaceNull` til fallback-tekst ved tomme værdier
- `breakLines` til at vise linjeskift som `<br>`
- `formatDecimalNumber` til lokal talvisning

## Branding og informationsbokse

Afhængigt af løsningen kan du også bruge konfigurationen til at styre:

- `brandName`
- `aboutBox`
- `startUpModal`
- `title`

Et eksempel kan være:

```json
{
  "brandName": "Mit brandnavn",
  "aboutBox": "<p>Her kan der indsættes HTML</p>",
  "startUpModal": "<p>Velkommen til kortløsningen</p>",
  "title": "Mit kort"
}
```

Det er nyttigt hvis forskellige fagløsninger skal have hver deres identitet, introduktion eller hjælpetekst.

## Undertryk startvindue i bestemte templates

Hvis `startUpModal` bruges, kan du vælge at undertrykke det i bestemte templates, fx print- eller blanke templates.

```json
{
  "startupModalSupressionTemplates": [
    "print.tmpl",
    "blank.tmpl"
  ]
}
```

## Embed og specialvisninger

Når Vidi bruges som embed på et andet website, spiller templates og konfiguration tæt sammen.

Som administrator vil du ofte skulle tage stilling til:

- om embed'et skal bruge en særlig template
- om feature-info skal vises på kortet eller i sidepanel
- om attributtabeller skal vises i bunden eller til højre
- om standardfunktioner som signatur, søgning eller baggrundskort skal vises

Hvis Vidi indlejres på et andet website, sker det typisk via `embed.js` og et `div`-element med `data-vidi-*` attributter. Typiske indstillinger er:

- `data-vidi-token` for hvilket projekt eller state der skal indlæses
- `data-vidi-width` og `data-vidi-height` for størrelse
- `data-vidi-tmpl` for hvilken template embed'et skal bruge
- `data-vidi-frame-name` hvis embed-API eller callbacks skal bruges
- `data-vidi-search`, `data-vidi-legend`, `data-vidi-layer` og lignende til at skjule eller vise funktioner

Et typisk eksempel kan være:

```html
<script src="https://vidi.swarm.gc2.io/js/embed.js"></script>
<div
  data-vidi-token="eyJ0aXRsZSI..."
  data-vidi-width="800px"
  data-vidi-height="600px"
  data-vidi-tmpl="embed.tmpl"
></div>
```

Hvis I arbejder med flere indlejrede kort eller vil styre lag fra værts-siden, kan embed-API'et også bruges til fx at tænde eller slukke lag efter load.

To typiske eksempler fra den ældre embed-dokumentation er:

```js
embedApi.switchLayer('planer.lokalplan', true, 'plankort')
embedApi.allOff('plankort')
```

Hvis embed'et bruger `data-vidi-frame-name="plankort"`, kan I også koble callbacks på når Vidi eller de aktive lag er klar:

```js
embedApi.vidiReady['plankort'] = () => {
  console.log('Vidi er klar')
}

embedApi.activeLayersReady['plankort'] = () => {
  console.log('Aktive lag er klar')
}
```

## `featureInfoTableOnMap`

Når denne er sat til `true`, vises feature-info tabeller i en popup på kortet i stedet for i sidepanelet.

```json
{
  "featureInfoTableOnMap": true
}
```

Det er især nyttigt i kompakte løsninger og embed-visninger.

## `vectorTable`

`vectorTable` styrer hvor attributtabellen skal placeres og hvor stor den skal være.

```json
{
  "vectorTable": {
    "position": "bottom",
    "width": "30%",
    "height": "250px"
  }
}
```

- ved `position: "bottom"` er `height` normalt den vigtigste værdi
- ved `position: "right"` er `width` normalt den vigtigste værdi

## Papirstørrelser og orientering

De konkrete printmuligheder afhænger af jeres printopsætning. Når brugeren i Vidi kan vælge mellem forskellige størrelser og retninger, er det i praksis et resultat af den konfiguration og det printsetup I stiller til rådighed.

## Godt administrator-check

Når print eller template ikke opfører sig som forventet, så tjek:

1. om den rigtige konfiguration faktisk bruges ved opstart
2. om den valgte template findes og kan indlæses
3. om `enabledPrints` matcher de skabeloner I forventer at se
4. om embed-visningen bruger særlige indstillinger som overstyrer standardopsætningen
5. om `featureInfoTableOnMap` og `vectorTable` passer til den ønskede brugeroplevelse
